# Analysis: Part 2.1 - Civilisation as Assembled Matter

## Document Purpose
Defines civilisation as thermodynamic maintenance stock Σ via four axioms; establishes Assembly Theory as one instantiation; partitions technosphere from biosphere/geosphere; derives maintenance floor and dynamics.

---

## AXIOMS (Assembly Framework)

**A1 (Extensiveness)**: Total maintenance burden = sum of component burdens. *From First Law.*

**A2 (Strict positivity of ξ)**: Every component requires strictly positive exergy for maintenance. *From Gouy-Stodola.*

**A3 (Monotonic decay)**: dΣ/dt = C(t) - δΣ. *From Second Law on unstable structures.*

**A4 (Operational partitionability)**: Counterfactual: if civilisational power → 0, does object disassemble on < geological timescale? *From boundary choice + physical fact.*

---

## DEFINITIONS

**D2.1: Thermodynamic Maintenance Stock Σ**
- Σ = Σᵢ σᵢ·nᵢ (assembly-steps)
- Any procedure satisfying A1–A4 yields equivalent maintenance floor
- *Units*: assembly-steps

**D2.2: Technosphere**
- Objects maintained by civilisational power throughput (per A4 counterfactual)

**D2.3: Geosphere / Biosphere**
- Excluded from Σ; maintained by non-civilisational flows

## THEOREMS

**T2.1: Maintenance Floor**
- P_maint ≥ (δξ/η_II)·Σ
- *Proof*: A2 (ξ>0), A3 (δ>0), η_II<1 (Second Law)
- *Dependencies*: A1–A4, Gouy-Stodola

**T2.2: Assembly Dynamics**
- dΣ/dt = C(t) - δΣ
- Growth requires C > δΣ; no pause button; collapse when C < δΣ
- *Dependencies*: A3

**T2.3: Tainter Convergence**
- Diminishing returns to complexity = ∂(service)/∂Σ ↓ while ∂(maintenance)/∂Σ = δξ/η_II constant
- *Dependencies*: T2.1, Tainter 1988
