## Document Purpose

## PROPOSITIONS

**P3.6: Integral Structure**
- Σ(t) = Σ₀e^(-δt) + ∫ C(τ)e^(-δ(t-τ)) dτ
- W(t) = ∫ Y(τ) dτ (Garrett); τ = W/Y ≈ 43 years

**P3.7: Zero Net Construction**
- C = δΣ → dΣ/dt = 0; P remains at current level indefinitely
- Steady state ≠ low energy

**P3.8: Zero Production Limit**
- C = 0 → Σ decays exponentially; at δ=2%, half-life ~35 yr
- "Halves" ≠ "disappears"

**P3.9: Carbon Lock-in = Assembly Lock-in**
- Every structure creates maintenance obligation; decarbonisation changes source not quantity
- P = Γ·Σ regardless of fuel

**P3.10: Temporal Batteries**
- Fossil/nuclear = steering reserves; burning for undirected growth = seed corn
