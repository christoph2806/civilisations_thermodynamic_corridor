## THEOREMS

**T3.6: Solvency Condition Decomposition**
- Y ≥ δW (Tier 1, physical) + rD (Tier 3, conventional)
- Conflating them = "growth physically necessary" error
- Reform can eliminate r, leaving only δW

**T3.7: Amplifiers Accelerate, Not Create**
- Trajectory exists without compound interest
- Debt steepens; does not originate
