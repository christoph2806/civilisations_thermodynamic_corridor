## THEOREMS

**T5.6: Corrected Theorem**
- Default trajectory non-viable
- Every viable trajectory requires Γ-reduction of magnitude with no historical precedent
- Viable region small; default misses it
- Nostos-then-kleos is generic viable trajectory

**T5.7: Existence Proof**
- Biosphere: Σ_bio ≫ Σ_tech, Γ_bio ≪ Γ_tech, 3.5 Gyr persistence
- Low-Γ equilibrium exists; landscape-dependence (Hanley) shows attractor can move
- Physical feasibility settled; institutional feasibility open

**T5.8: Burden-Transfer (P5–P8)**
- P5: ΔP_tot = ΔΣ_bio(βΓ_tech − Γ_bio) > 0 when biosphere replaced
- P6: K_combined ⊂ K_tech
- P7: β ≥ 1; ∂β/∂a_bio > 0 (deep assembly costlier to replace)
- P8: Biosphere preservation enlarges viable corridor

**T5.9: Accelerating Kernel Contraction (C5)**
- Shallow-assembly lost first (T2 on biosphere); deep-assembly costlier (P7b)
- Each unit of loss costs more than last
